Deployment
From git push to live in minutes

Designed for Railway. Runs on any platform that supports Python and PostgreSQL.

1

Clone & install

Clone the repo and install Python dependencies.

git clone https://github.com/harsh23111157/event-management.git
cd event-management
pip install -r requirements.txt
2

Configure environment

Copy .env.example to .env and fill in your values.

DEBUG=True
SECRET_KEY=your-secret-key
DATABASE_URL=sqlite:///db.sqlite3  # or postgres://...
OPENROUTER_API_KEY=sk-or-v1-...  # optional AI features
3

Run locally

python manage.py migrate
python manage.py seed_demo_data
python manage.py runserver

Open localhost:8000 and log in with admin / admin12345.

4

Deploy to Railway

Connect the GitHub repo to Railway. Add a PostgreSQL plugin, then set these variables:

DJANGO_SETTINGS_MODULE=config.settings.production
SECRET_KEY=<generate with manage.py>
ALLOWED_HOSTS=your-app.up.railway.app
CSRF_TRUSTED_ORIGINS=https://your-app.up.railway.app
DEBUG=False

Railway picks up start.sh — migrations, seeding, static files, and gunicorn run automatically.
