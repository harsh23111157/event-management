STAGE 1 Planning & Venue Allocation (Status: Draft)
🎯 Key Actions
  • Create event with Title, Type, and Target Dates.
  • Assign Venue and validate attendee capacity vs expected guests.
  • Propose estimated budget and assign accountable Event Manager.
👥 Roles Involved
  • Event Manager: Creator & Lead Author.
  • Admin: Initial creator (optional).
🔒 System Rules
  • Expected attendees cannot exceed selected venue capacity.
  • End date must be greater than or equal to start date.
STAGE 2 Governance & Approval Gate (Status: Submitted → Approved)
🎯 Key Actions
  • Manager clicks "Submit for Review" moving state from DRAFT → SUBMITTED.
  • Admin reviews budget feasibility, venue availability, and timeline.
  • Admin clicks Approve or Reject with Reason.
👥 Roles Involved
  • Organization Admin: Sole authority for formal approval.
  • Event Manager: Receives feedback/rejection notes if revisions needed.
🔒 System Rules
  • Tasks and expenses cannot be executed until event is formally APPROVED.
  • Rejections generate an actionable notification alert in Manager dashboard.
STAGE 3 Team Logistics & Vendor Contracting (Status: Approved)
🎯 Key Actions
  • Assign Staff Members with designated roles (Tech Support, Greeter, Coordinator).
  • Link Verified Vendors (Catering, Security, A/V, Decor) with contracted amounts.
  • Dispatch prioritized work breakdown tasks with due dates.
👥 Roles Involved
  • Event Manager: Team & Vendor coordinator.
  • Staff: Receives notification of assigned tasks & shifts.
🔒 System Rules
  • Tasks flagged as CRITICAL are highlighted on executive dashboards.
  • Vendor assignments track agreed contract amounts for budget cross-checking.
STAGE 4 Live Execution & Attendance Check-in (Status: In Progress)
🎯 Key Actions
  • Event transitions to IN_PROGRESS on event launch day.
  • Staff check in at the venue (recorded as PRESENT or LATE).
  • Real-time task progression: staff mark items COMPLETED.
👥 Roles Involved
  • Staff: Real-time on-site task completion & attendance.
  • Event Manager: Live floor coordinator.
🔒 System Rules
  • Overdue tasks automatically trigger warnings in task list and executive feeds.
  • Attendance logs record exact timestamps for payroll and shift auditing.
STAGE 5 Continuous Expense Auditing & Budget Control
🎯 Key Actions
  • Log operational expenses with category (Venue, Catering, Travel, Marketing).
  • Attach vendor invoices, payment slips, and receipt documentation.
  • Finance or Admin reviews and approves expense reimbursement claims.
👥 Roles Involved
  • Finance Officer / Admin: Review & Approval authority.
  • Managers & Staff: Expense claimants.
🔒 System Rules
  • 80% Utilization: System triggers Amber warning badge.
  • 90% Utilization: System triggers Critical Rose warning banner.
STAGE 6 AI Copilot Analysis & Post-Event Reconciliation (Status: Completed)
🎯 Key Actions
  • Manager or Admin marks event COMPLETED after closure.
  • Run AI Copilot for automated risk assessment & reconciliation checklist.
  • Generate comprehensive Event, Task, Vendor, and Financial Analytics Reports.
👥 Roles Involved
  • AI Copilot (OpenRouter LLM): Automated auditor.
  • All Stakeholders: Review final analytics and lessons learned.
🔒 System Rules
  • Audit logs permanently store full chronological history of all updates.
  • Completed events remain archived and searchable for historical benchmarking.

Event Status State Machine
Allowed status transitions and governance validation gates.
DRAFT Created by Manager
→
SUBMITTED Awaiting Admin
→
APPROVED Admin Authorized
→
IN_PROGRESS Live Execution
→
COMPLETED Reconciled & Closed
REJECTED Branch Needs Revision
If an event proposal lacks budget details or exceeds venue capacity, the Admin can mark it REJECTED with feedback. The Manager modifies details and resubmits back to SUBMITTED.
CANCELLED Branch Terminal State
If an event is called off before or during execution, authorized managers or admins mark it CANCELLED. All pending tasks are archived and final balance calculations freeze.
